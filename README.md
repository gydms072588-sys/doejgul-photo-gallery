# 됒굴포토 v3.5

공개 사이트: https://gydms072588-sys.github.io/doejgul-photo-gallery/

## 방문자

- 한 번 클릭/탭은 원본 확대, 두 번 클릭/탭은 하트 선택입니다. 사장 PICK은 선택할 수 없습니다.
- PC 4열, 모바일 2열 모두 같은 12개 단위로 페이지를 나눕니다. 1쪽 01~12, 2쪽 13~24, 3쪽 25~36, 4쪽 37~48입니다. 마지막 쪽은 남은 타일만 표시합니다.
- 상단 타입 이동과 하단 숫자 샘플 페이지는 별개입니다. 타입 변경은 샘플 1쪽으로 돌아가며 하트 선택은 유지합니다. 많은 페이지는 비활성 말줄임표로 생략하고 현재 쪽에는 aria-current를 제공합니다.
- 상단은 개구리와 하트만 표시합니다. 선택 현황의 **선택표 전체보기**는 하트/PICK을 나눈 미리보기 모달을 열며 **선택표 PNG 저장**은 모달 안에만 있습니다.
- PICK은 선택 타입의 참고 사진으로 PNG에 포함합니다. 하트가 없으면 현재 타입의 PICK을 포함합니다. 금액과 선택 수에는 가산하지 않습니다. 타입·샘플 번호·워터마크를 유지합니다.
- **주문 예상 금액**은 일반 사진 수×기본 단가와 개별 특수 금액의 합계입니다. 기본은 50길이며, 개별 금액은 기본 단가에 더하지 않고 대체합니다. 협의 사진은 숫자 합계에서 제외하고 확정 가능 소계 및 최종 문의 안내를 표시합니다.
- **신청서 안내**는 모든 방문자 공통의 읽기 전용 템플릿입니다. **신청하기**는 안내·복사 모달만 열며 자동 접수나 결제가 아닙니다. 외부 채팅에서 작성해 전달합니다. 신청자의 개인정보를 입력·저장하지 않습니다.

## 관리자

- 개구리를 4초 안에 5회 눌러 진입합니다. 이 동작은 보안 인증이 아닙니다.
- 기존 타입·샘플 관리, 사진 업로드·교체·삭제·일괄 등록·중복 확인·타일 추가·제거를 유지합니다.
- 사진 편집에서 **기본 단가 / 특수 사진 개별 금액 / 금액 협의**와 가격 메모를 설정합니다. 개별 금액은 0 이상의 정수입니다. 가격은 사진 고유 ID에 연결되므로 타입 순서 변경이나 사진 표시 번호 변경으로 섞이지 않습니다.
- **가격·신청 안내**에서 일반 기본 단가, 공통 안내 제목·부제·양식 레이블·도움말·순서·문의 문구를 편집합니다. 초기 제목은 신청서 안내, 부제는 오마카세 타입입니다.
- 미리보기 변경을 **GitHub에 게시**해야 공개됩니다. 토큰은 메모리에서만 사용하며 소스·JSON·localStorage·sessionStorage에 저장하지 않습니다. 성공 및 관리자에서 나갈 때 지웁니다. 충돌·권한 오류·부분 업로드 재시도 흐름을 유지합니다.

## 데이터와 마이그레이션

기존 schemaVersion 3, types[].photos[] 배열, 타입·사진 ID, 사진 경로, 방문자 선택 키를 유지합니다. 현재 등록 사진·타입·샘플 수를 변경하지 않습니다. 와이어프레임의 37개 샘플은 테스트용일 뿐 실제 데이터에 추가하지 않습니다.

- `defaultPriceGil`: 기본 50. 과거 타입별 또는 전체 총액은 가격 계산에 사용하지 않습니다.
- 사진의 `priceMode`: default/custom/negotiation, `customPriceGil`: 0 이상 정수 또는 null, `priceNote`: 안내 메모.
- `applicationTitle`, `applicationSubtitle`, `applicationForm`: 공통 공개 템플릿.

누락된 가격 필드는 읽을 때 기본 단가로 하위 호환하며 새 필드는 관리자 게시 시 저장합니다. 과거 금액 자료와 보류된 로컬 기록을 임의 삭제하지 않습니다. 실제 의뢰 내용·수령 내역은 공개 게시 대상이 아닙니다.

## 검수와 배포

PC 및 모바일 에뮬레이션에서 48장/37장 페이지 범위, 숫자 이동·활성 상태, 50+50=100, 50+120=170, 협의 제외 소계, PICK 제외·PNG 참고 섹션, 읽기 전용 안내, 360px 가로 넘침을 검수합니다. 관리자 게시 및 클립보드 오류는 모의 API로 검사합니다. 실제 Pages 배포 상태는 별도로 확인하며 실기기 검수는 별도입니다.

Settings → Pages → main / (root) 배포를 유지합니다. HTML에 CSS와 JavaScript를 내장하며 사진과 gallery-data.json은 함께 제공해야 합니다.
