# 됒굴포토 v3.3

공개 사이트: https://gydms072588-sys.github.io/doejgul-photo-gallery/

## 방문자

- 상단 타입 바로가기, PC 4열·모바일 2열, 타입 안에서 12개 단위 페이지 이동을 유지합니다.
- 한 번 클릭은 확대, 두 번 클릭은 하트 선택입니다. 사장 PICK은 확대만 가능하며 하트 선택 개수에 포함하지 않습니다.
- 타입 안내는 PC의 갤러리 오른쪽 사이드바, 모바일의 갤러리 아래에 있습니다.
- 공통 `publicPrepaidGil`만 선불 길 총액으로 표시합니다. 미설정은 금액 미설정입니다. 선택 수로 계산하지 않으며 과거 타입별 금액을 합산·이전하지 않습니다.
- 신청 양식은 순수 텍스트입니다. 복사 후 외부 채팅에서 작성해 전달합니다. 복사 실패 시에도 편집 컨트롤 없이 텍스트를 선택해 복사합니다.
- PNG에는 사용자 선택과 사장 PICK(참고)을 별도 섹션으로 표시합니다. 선택된 타입들의 PICK을 포함하고, 하트가 없으면 현재 타입의 PICK을 포함합니다. 모든 샘플 번호·타입·썸네일·50% 워터마크를 유지합니다. 하트와 PICK이 모두 없으면 저장하지 않습니다.
- 복사 텍스트에도 같은 범위의 하트·PICK 목록이 포함됩니다.

## 관리자

- 상단 개구리를 4초 안에 5회 클릭합니다. 이 방식은 인증이 아닙니다.
- 타입·샘플 관리: 기존 가변 타일 추가·삭제·사진 교체·일괄 업로드·중복 확인·사장 PICK을 유지합니다.
- 공개 안내 설정: 모든 타입에 공통인 선불 길 총액 하나, 타입별 촬영 설명, 공통 양식 레이블·도움말·순서·안내 문구를 편집합니다.
- 공통 금액은 비워 두거나 0 이상의 정수로 입력합니다. 개인별 의뢰 금액은 여기에 입력하거나 공개 게시하지 마세요.
- 미리보기 수정은 GitHub 게시 전까지 공개되지 않습니다. 토큰은 해당 저장소의 Contents 쓰기 권한만 사용하며 영구 저장하지 않습니다.
- 이전 수령 기록 기능은 제거했습니다. 기존 브라우저 저장값은 읽기·수정·삭제하지 않으므로 남아 있습니다.

## 데이터 보존과 검수

기존 schemaVersion 3, 타입·샘플 ID·순서·사진 경로·선택 저장 키를 유지합니다. 이번 변경은 index.html과 README.md이며 기존 gallery-data.json과 이미지 파일을 초기화하지 않습니다. 과거 타입별 prepaidGil 값이 있더라도 보존 자료일 뿐 표시·계산에는 사용하지 않습니다. 새 공통 총액은 관리자가 공개 설정을 게시할 때 저장됩니다.

PC 및 모바일 터치 에뮬레이션에서 읽기 전용 양식·공통 총액·PICK 범위·선택 PNG·복사 텍스트·사이드바·오래된 로컬 기록 보존을 검수합니다. 게시·클립보드 오류는 모의 API로 검사하고 실제 GitHub Pages 배포도 별도 확인합니다. 모바일 실기기는 별도 확인이 필요합니다.
